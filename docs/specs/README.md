# Specs

One file per feature, named `NN-slug.md` to match its PR number in `docs/ROADMAP.md`. A spec holds:

- **Problem:** what is wrong or missing, and for whom.
- **Who it's for:** student, staff, or developer.
- **Scenarios:** a table of concrete situations and the expected result. This is the definition of done, and the PR's tests and review page check against it.
- **Out of scope:** what this PR deliberately does not do.

Choices that need George's input go on a decision page first and land here once marked.
